# Theory_Ecotox
Lecture materials for the M.Sc. course Theoretical Ecotoxicology: Concepts and Applications

University Duisburg-Essen, 2026

Contributors: Hanh Hong Nguyen, Ralf B. Schäfer, André Gergs, Marie Brasseur, Helena Bayat, Paul Ozoh, Iris Madge-Pimentel, Verena Schreiner, Silviu Bobric

To have the entry level skills required for this course, students are offered free online courses before this course starts. The free online courses are supported by [DataCamp](https://www.datacamp.com/universities), an interactive platform for data and AI skills. DataCamp Classrooms offers free licenses for educators and students, with 500+ courses and 100+ real-world projects to learn R, Python, SQL, and more.
